# Local Command Center UI

Run:

```bash
npm run review
```

Then open:

```text
http://127.0.0.1:8787/
```

The home page shows the Command Center using anonymized demo cases/incidents and the current local approval state.

Sections:
- Top priorities
- Active incidents
- Waiting provider
- Client updates ready
- Pending approvals

The original approval screen remains available at:

```text
http://127.0.0.1:8787/review
```

No external messaging or live production system is connected.
