# V0.2 release notes

V0.2 turns the initial transaction-support workflow into a complete generic operations engine.

## Added

- deterministic intent parsing and escalation policy;
- transaction reply composition and risk classification;
- provider reply correlation;
- case lifecycle and approvals;
- common-incident intelligence and coordination;
- health-backed incident recovery/closure;
- SLA follow-ups;
- P0-P3 triage;
- Command Center UI;
- search and focus views;
- case/incident drill-down;
- shadow operator actions;
- local audit/persistence;
- anonymized scenario simulator.

## Operating mode

V0.2 remains **read-only and shadow-first**.

The public demo has no live panel credentials, no production merchant/provider data, no WhatsApp integration and no financial execution capabilities.

## Next phase

Private/live integration should prove, in order:

1. authenticated session + manual OTP lifecycle;
2. exact read-only lookup mapping;
3. merchant/account/channel scope enforcement;
4. live shadow accuracy;
5. provider/client message transport;
6. sustained operational evidence before considering any selective low-risk automation.
