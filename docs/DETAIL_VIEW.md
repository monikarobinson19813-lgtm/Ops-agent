# Case and incident drill-down

The Command Center list is only the starting point.

Each case/incident can open a detail view showing:
- priority and next action;
- current status/facts;
- linked incident or affected cases;
- due follow-up;
- approvals;
- a time-ordered operational timeline.

Local demo URL:

```text
/detail?type=CASE&id=OPS-DEMO-CNR
```

or:

```text
/detail?type=INCIDENT&id=INC-DEMO-1
```

This remains a read-only/shadow-mode operational view.
